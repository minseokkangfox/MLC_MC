# MLC 렐름 관리 애드온 (Bedrock / 모바일)

렐름용 비헤이비어 팩입니다. 스크립트 API **정식 버전**(`@minecraft/server` 2.3.0)만 사용하므로
**실험적 기능(베타 API)을 켤 필요가 없습니다.** Minecraft 1.21.120 이상에서 동작합니다.

## 설치 (모바일)

1. `dist/MLC_MC.mcpack` 파일을 폰에 받아서 엽니다 → 마인크래프트가 자동으로 가져옵니다.
2. 렐름 설정 → **비헤이비어 팩** → `MLC 렐름 관리 애드온` 을 **활성화**합니다.
3. 렐름에 접속하면 적용됩니다.

## 관리자 명령어

관리자: **minseok Kang579** (대소문자·띄어쓰기 무시). 다른 사람이 쓰면 거부됩니다.
치트가 꺼져 있어도 사용할 수 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `/mlc 게임모드` | 강제 서바이벌 켜기 / 다시 입력하면 끄기 |
| `/mlc 상태` | 현재 상태 |
| `/mlc 스캔` | 주변 청크 커맨드 블록 즉시 다시 검사 |
| `/mlc 로그` | 제거한 커맨드 블록 위치 (최근 20개) |

영어로 `/mlc gamemode`, `/mlc status`, `/mlc scan`, `/mlc log` 도 됩니다.

## 기능

### 1. 강제 서바이벌 + 숨겨진 게임모드 커맨드 제거
`/mlc 게임모드` 를 켜면:
- 관리자를 뺀 모든 플레이어의 게임모드 변경을 **바로 취소**합니다.
- 취소가 버그로 실패해도 0.5초마다 **계속 서바이벌로 되돌립니다.**
- 모든 플레이어 주변 6청크 안의 **커맨드 블록(일반/반복/연쇄)과 커맨드 블록 마인카트를 찾아서 제거**합니다.
  누가 게임모드가 바뀌려 하면 그 주변을 즉시 다시 검사하고, 관리자에게 위치를 알려줍니다.
- 제거된 위치는 `/mlc 로그` 로 볼 수 있습니다.

> 스크립트로는 커맨드 블록 안의 명령어를 읽을 수 없기 때문에, 켜져 있는 동안에는
> 로딩된 **모든** 커맨드 블록이 제거됩니다. 남겨야 할 커맨드 블록이 있으면
> 다 찾은 뒤 다시 입력해서 꺼 주세요. (`config.js` 의 `commandBlock.remove` 를 `false` 로 하면 위치만 알려줍니다.)

### 2. 신규 플레이어 먼 곳 스폰
- 처음 들어온 플레이어는 월드 스폰에서 **2000~4000칸** 떨어진 랜덤 육지로 보내고, 그곳을 스폰 지점으로 설정합니다 (죽으면 거기서 부활, 침대가 있으면 침대 우선).
- 하늘에서 천천히 떨어지며(느린 낙하 + 저항) 땅이 로딩되면 착지시킵니다. 물/용암이면 다른 곳을 찾습니다.
- **이미 들어왔던 플레이어는 그대로입니다.** 애드온 설치 전 기록이 없으므로
  "스폰 64칸 안에서 접속 + 인벤토리 빈칸 + 레벨 0 + 갑옷 없음" 인 경우에만 신규로 판단합니다.

### 3. 위더 2시간 제한
- 위더가 소환되고 **2시간(실제 시간) 안에 못 잡으면 사라집니다.** 이때 네더의 별은 떨어지지 않습니다.
- 2시간 안에 정상적으로 잡으면 네더의 별은 원래대로 떨어집니다.

### 4. TNT / TNT 카트 테러 방지
- TNT는 허용하지만, 폭발은 **자연 생성 블럭**과 **터트린 사람이 설치한 블럭**만 부숩니다.
  다른 사람이 설치한 블럭은 안 터집니다.
- 터트린 사람 = 부싯돌/화염구로 불붙인 사람, 없으면(레드스톤 등) TNT를 설치한 사람.
  디스펜서 TNT는 디스펜서를 설치한 사람 기준입니다. 주인을 알 수 없는 TNT는 자연 블럭만 부숩니다.
- TNT 카트도 같은 규칙입니다 (카트를 레일에 놓은 사람 기준).
- 크리퍼 등 다른 폭발은 바닐라 그대로입니다.

> **주의:** 블럭 주인은 **애드온을 설치한 뒤부터** 기록됩니다. 설치 전에 지은 건물은
> "자연 블럭" 취급이라 TNT에 부서질 수 있습니다. 피스톤으로 옮긴 블럭도 주인 기록이 따라가지 않습니다.

### 5. 북밴 방지
- **책**(책과 깃펜 / 작성된 책) 한 권이 16KB를 넘으면 제거합니다.
- **셜커 상자** 안 아이템 전체 용량이 64KB를 넘으면 셜커 상자째 제거합니다 (설치된 셜커는 블럭째, 아이템 상태면 아이템째).
- 검사 시점: 플레이어 인벤토리(2초마다 + 접속 직후), 셜커 설치 시, 상자/셜커 등 컨테이너를 열 때, 바닥에 떨어진 아이템.
- 손으로 쓴 정상적인 책은 이 한도보다 훨씬 작아서 영향이 없습니다.

> 엔더 상자 안은 스크립트로 볼 수 없어서 검사하지 못합니다. 이미 북밴으로 접속이 안 되는
> 플레이어는 렐름 백업 복원이 필요할 수 있습니다.

## 설정 바꾸기
`behavior_pack/scripts/config.js` 에서 거리, 시간, 용량 한도 등을 바꾼 뒤 `./build.sh` 로 다시 묶고,
`manifest.json` 의 `version` 숫자를 올려서 다시 적용하면 됩니다.

## 렐름 팁
커맨드가 **틱킹 에어리어**에 있을 수도 있습니다. 관리자가 `/tickingarea list all-dimensions` 로 확인하고
필요하면 `/tickingarea remove_all` 로 지우세요 (치트 필요).
