# MLC 렐름 관리 애드온 (Bedrock / 모바일)

렐름용 비헤이비어 팩입니다. 스크립트 API **정식 버전**(`@minecraft/server` 2.3.0)만 사용하므로
**실험적 기능(베타 API)을 켤 필요가 없습니다.** Minecraft 1.21.120 이상에서 동작합니다.

## 설치 (모바일)

1. `dist/MLC_MC.mcpack` 파일을 폰에 받아서 엽니다 → 마인크래프트가 자동으로 가져옵니다.
2. 렐름 설정 → **비헤이비어 팩** → `MLC 렐름 관리 애드온` 을 **활성화**합니다.
3. 렐름에 접속하면 적용됩니다.

관리자: **minseok Kang579** (대소문자·띄어쓰기 무시). 관리자 전용 명령어는 다른 사람이 쓰면 거부됩니다.

| `/mlc 상태` | 관리자 | 현재 상태 |

> 영어 `/report`, `/reports`, `/ban`, `/unban` 을 쓰면 똑같이 동작합니다.

## 기능

### 1. 강제 서바이벌 + 숨겨진 게임모드 커맨드 제거
`/mlc 게임모드` 를 켜면:
- 관리자를 뺀 모든 플레이어의 게임모드 변경을 **바로 취소**합니다.
- 취소가 버그로 실패해도 0.5초마다 **계속 서바이벌로 되돌립니다.**
- 모든 플레이어 주변 10청크 안의 **커맨드 블록(일반/반복/연쇄)과 커맨드 블록 마인카트를 찾아서 제거**합니다.
  누가 게임모드가 바뀌려 하면 그 주변을 즉시 다시 검사합니다.
- 제거했다는 메시지는 바로 뜨지 않고, **관리자가 접속할 때 관리자에게만** 모아서 보여줍니다. `/mlc 로그` 로도 볼 수 있습니다.

> 스크립트로는 커맨드 블록 안의 명령어를 읽을 수 없기 때문에, 켜져 있는 동안에는
> 로딩된 **모든** 커맨드 블록이 제거됩니다. 남겨야 할 커맨드 블록이 있으면
> 다 찾은 뒤 다시 입력해서 꺼 주세요. (`config.js` 의 `commandBlock.remove` 를 `false` 로 하면 위치만 알려줍니다.)

### 2. 신규 플레이어 먼 곳 스폰
- 처음 들어온 플레이어는 월드 스폰에서 **2000~4000칸** 떨어진 랜덤 육지로 보내고, 그곳을 스폰 지점으로 설정합니다 (죽으면 거기서 부활, 침대가 있으면 침대 우선).
- 하늘에서 천천히 떨어지며(느린 낙하 + 저항) 땅이 로딩되면 착지시킵니다. 물/용암이면 다른 곳을 찾습니다.
- 한 번 끝난 플레이어는 다시 들어와도 옮기지 않습니다. 옮기는 도중에 나갔다면 다시 들어올 때 **같은 목적지**로 이어서 진행합니다.
- **이미 들어왔던 플레이어는 그대로입니다.** 애드온 설치 전 기록이 없으므로
  "스폰 64칸 안에서 접속 + 인벤토리 빈칸 + 레벨 0 + 갑옷 없음" 인 경우에만 신규로 판단합니다.

### 3. 위더 2시간 제한
- 위더가 소환되면 **소환한 사람 화면 아래에만** 사라지기까지 남은 시간이 표시됩니다 (다른 사람에게는 안 보임).
- 위더가 소환되고 **2시간(실제 시간) 안에 못 잡으면 사라집니다.** 이때 네더의 별은 떨어지지 않습니다.
- 2시간 안에 정상적으로 잡으면 네더의 별은 원래대로 떨어집니다.

### 4. TNT / TNT 카트 테러 방지
- TNT는 허용하지만, 폭발은 **자연 생성 블럭**과 **터트린 사람이 설치한 블럭**만 부숩니다.
  다른 사람이 설치한 블럭은 안 터집니다.
- 터트린 사람 = 부싯돌/화염구로 불붙인 사람, 없으면(레드스톤 등) TNT를 설치한 사람.
  디스펜서 TNT는 디스펜서를 설치한 사람 기준입니다. 주인을 알 수 없는 TNT는 자연 블럭만 부숩니다.
- TNT 카트도 같은 규칙입니다 (카트를 레일에 놓은 사람 기준).
- 문·침대 같은 두 칸짜리 블럭은 두 칸 모두 주인이 기록되고, 다른 사람 블럭(문, 침대, 횃불, 레일 등)을 **받치고 있는 블럭**도 터지지 않아서 같이 떨어지지 않습니다.
- **상자·통·화로 등 컨테이너는 TNT로 절대 안 터집니다** (애드온 설치 전에 놓은 상자도).
- 크리퍼 등 다른 폭발은 바닐라 그대로입니다.

> **주의:** 블럭 주인은 **애드온을 설치한 뒤부터** 기록됩니다. 설치 전에 지은 건물은
> "자연 블럭" 취급이라 TNT에 부서질 수 있습니다. 피스톤으로 옮긴 블럭도 주인 기록이 따라가지 않습니다.

### 5. 북밴 방지
- **책**(책과 깃펜 / 작성된 책) 한 권이 16KB를 넘으면 제거합니다.
- **셜커 상자** 안 아이템 전체 용량이 64KB를 넘으면 셜커 상자째 제거합니다 (설치된 셜커는 블럭째, 아이템 상태면 아이템째).
- 검사 시점: **셜커를 부수는 순간**(아이템이 되기 전), 폭발로 셜커가 부서질 때, 셜커 설치 시, 컨테이너를 열 때, 플레이어 인벤토리(2초마다 + 접속 직후), 바닥에 떨어진 책.
- 아이템 상태의 셜커는 스크립트로 안을 볼 수 없어서, 블럭 상태일 때(부수기 직전) 막습니다. 그래서 위험한 셜커가 땅에 떨어져 다른 사람이 줍는 일을 막습니다.
- 손으로 쓴 정상적인 책은 이 한도보다 훨씬 작아서 영향이 없습니다.

> 엔더 상자 안은 스크립트로 볼 수 없어서 검사하지 못합니다. 이미 북밴으로 접속이 안 되는
> 플레이어는 렐름 백업 복원이 필요할 수 있습니다.

### 6. 신고 (`/신고`)
1. 플레이어 목록 창이 뜹니다. **위: 접속 중**, **아래: 들어왔다 나간 플레이어**.
2. 플레이어를 누르면 **신고 종류**(테러, 욕설, 괴롭힘, 핵, 버그 악용, 사기, 도배, 기타), **제목**, **자세한 설명**, **스크린샷 링크**를 입력합니다.
3. 전송하면 관리자에게 바로 알림이 가고, 관리자가 없으면 **나중에 관리자가 접속할 때 관리자에게만** "새 신고 N건" 이 뜹니다 (읽을 때까지).
- 같은 플레이어를 두 번 신고할 수 없습니다.
- 마인크래프트 창에서는 사진 파일을 직접 올릴 수 없어서, 스크린샷은 디스코드 등에 올린 **링크**를 붙여넣는 방식입니다.
- 플레이어 머리는 실제 스킨이 아니라 기본 캐릭터 아이콘으로 표시됩니다 (스크립트로 스킨을 가져올 수 없음).

### 7. 신고함 (`/신고함`, 관리자)
- 신고 당한 플레이어 목록 + **신고 횟수** (많은 순, 안 읽은 신고 표시).
- 플레이어를 누르면 **신고한 플레이어 목록** → 눌러서 제목/설명/스크린샷 확인.
- 신고함에서 바로 **밴**, 신고 삭제 가능.

### 8. 밴 (`/밴`, `/밴해제`, 관리자)
- `/밴`: 접속 중 + 나간 플레이어 목록 → 선택 → **카테고리**(핵, 악용, 괴롭힘, 욕설, 테러, 사기, 도배, 기타) → **이유**(안 써도 됨) → 밴.
- 밴 당하면 **바로 kick** 되고, 다시 들어올 때마다 다시 kick 됩니다 (자리를 차지하지 않음). kick 화면에 밴 이유가 나옵니다. `/밴해제` 하면 더 이상 kick 하지 않습니다.
- kick 은 **진짜 커맨드 블록**이 합니다 (관리자가 예전에 커맨드 블록으로 반복 kick 하던 방식과 같음).
  밴 당한 플레이어 발밑 맨 아래(기반암 층)에 반복 커맨드 블록을 1초 동안 놓았다가 원래 블록으로 되돌립니다.
  스크립트가 직접 `/kick` 하면 "호스트에 의해 차단되었습니다" 가 뜨면서 렐름이 다시 켜질 때까지 못 들어오는 문제가 있었습니다.
  커맨드 블록이 꺼져 있으면(게임 규칙 commandblocksenabled) 예전 방식으로 kick 합니다.
- 카테고리나 디스코드 링크를 바꾸면 `tools/make_kick_structures.py` 도 똑같이 바꾸고 실행해서 구조물을 다시 만들어야 합니다.
- `config.js` 의 `ban.useKick` 을 `false` 로 하면 kick 대신 접속한 채로 잠그는 방식이 됩니다.
- 화면에 뜨는 메시지:
  `서버 규칙을 위반 했습니다. (카테고리) 를 위반 (이유) 이 밴에 문제가 있으면 관리자에게 문의하세요 https://discord.gg/s63XD2AuNy`
- **테러** 로 밴하면 그 플레이어의 **최근 5시간 행동을 전부 되돌립니다**: 설치한 블럭 제거(불 켜진 화로처럼 모양이 바뀐 것 포함), 부순 블럭 복구, **부순 상자·통·화로 등은 내용물까지 복구**, **남의 상자를 열어서 가져간 아이템도 열기 전 상태로 복구**, 그 사람 TNT/TNT 카트로 터진 블럭 복구, 부은 용암/물과 **흘러간 용암/물 제거**, 그 때문에 생긴 조약돌/흑요석 제거, 붙인 불 제거.
  로딩 안 된 곳은 누가 근처에 가서 청크가 로딩되면 이어서 되돌립니다.
  그 자리에 다른 사람이 나중에 지은 블럭만 남겨두고, 그 사이 생긴 풀·떨어진 모래/자갈·흘러든 물 등은 덮어서 복구합니다.
- `/밴해제`: 밴 목록 → 누르면 카테고리/이유/날짜/밴한 관리자 확인 → 해제. 밴은 플레이어 id와 이름 둘 다로 확인하고, 해제할 때도 같은 플레이어의 밴 기록을 전부 지웁니다.

> 행동 기록은 이번 업데이트 설치 후부터 쌓입니다. 상자 내용물 복구는 v1.2.0 설치 후 부순 상자부터 됩니다.
> 퍼진 불/용암이 태운 블럭, 상자를 열어서 가져간 아이템은 되돌리지 못합니다.
> 나간 플레이어 목록도 이번 업데이트 설치 후 한 번이라도 접속한 플레이어만 보입니다.
> 렐름 주인(호스트) 계정은 내보낼 수 없습니다.


## 설정 바꾸기
`behavior_pack/scripts/config.js` 에서 거리, 시간, 용량 한도 등을 바꾼 뒤 `./build.sh` 로 다시 묶고,
`manifest.json` 의 `version` 숫자를 올려서 다시 적용하면 됩니다.

## 렐름 팁
커맨드가 **틱킹 에어리어**에 있을 수도 있습니다. 관리자가 `/tickingarea list all-dimensions` 로 확인하고
필요하면 `/tickingarea remove_all` 로 지우세요 (치트 필요).
